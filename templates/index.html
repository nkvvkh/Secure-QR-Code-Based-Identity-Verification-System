Secure QR Code-Based Identity Verification System

Issue tamper-proof QR identity cards and check them in seconds. Each QR code holds only a random token and an HMAC-SHA256 signature. Names and other details stay in the server database.

📷 Scan a QR code 🔐 Admin login
🎲

Random tokens

Every identity gets a 256-bit token from Python's secrets module. Only its SHA-256 hash is stored.

✍️

HMAC-SHA256 signature

The server signs each token with a secret key. Forged or edited QR codes fail a constant-time signature check.

🚫

Instant revocation

Admins can revoke an identity at any time. Expired and revoked QR codes are rejected on the server.

How it works

  1. An admin registers a person: name, user ID, department and expiry date.
  2. The server creates a random token, signs it, and shows a QR code that contains only the token and signature.
  3. A verifier scans the QR code with a webcam or uploads an image of it.
  4. The server checks the signature, finds the token in the database, then checks expiry and revocation.
  5. The result is shown as VALID INVALID EXPIRED or REVOKED.
